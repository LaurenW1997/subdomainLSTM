# 11 论文风格的图和幻灯片

2026-11-10 版本：主模型换成目前结果最好的一版，**水位 + 风 + 上游流量 + 降雨**（降雨为 AORC 实测，15 km 均值，过去 72 小时加未来 6 小时），对照是当前业务模型（水位 + 风 + 上游流量，无降雨）。

**注意**：未来 6 小时的降雨用的是实测值，业务上只有预报，所以这套图是"降雨预报完全准确"时的上限。幻灯片第 1、4 页和最后一页都写明了这一点；最后一页给出换成 HRRR 预报降雨后的结果（7.39 / 7.66 cm，对无降雨的 7.65 cm）。业务模型目前仍不含降雨。上一版（业务模型对只用水位）在 git 历史里（提交 582927d）。

21 个代表站（不含 CRMS）、三个窗口（飓风 / 涨水 / 平常）：

- `station_<站号>.png` / `.pdf`：一站一张三联图。黑线观测；三条蓝线从浅到深是提前 1、3、6 小时的预报，每条是连续线（某小时的值 = 1、3 或 6 小时前发出的预报）；灰底是峰值前后 24 小时；RMSE 写在面板标题第二行。只画加降雨的模型。
- `rmse_vs_lead.png`：RMSE 随提前量（1–6 h）变化，六类站各一条，实线加降雨，虚线不加降雨，阴影四分位范围。
- `rmse_box_by_type.png`：各类站逐站 6 h RMSE 的箱线图，有无降雨对比。
- `rmse_map.png`：443 个非 CRMS 站的 6 h RMSE 地图，方框是 21 个代表站。
- `forecast_figures.pptx`：27 页，白底黑字 Times New Roman，无标题页，每页一张图加一两句话。
- `data/<前缀>_<站号>.csv`：三联图用的数据（每小时观测和各提前量有效的预报；f 列是加降雨的模型，b 列是不加降雨的业务模型），由 `scripts/report/extract_windows.py` 在 sv7 生成。

脚本：`scripts/report/paper_figs.py`（station / lead / box / map）、`scripts/report/slides_figures.py`。
