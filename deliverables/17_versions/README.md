# 17 各版本横向对比

把从开始到现在的每个版本放在一起比，帮助决定下一步。只用业务站（USGS 和 NOAA，443 个；CRMS 只用于训练，不出现在这里），测试期 2024-01 到 2025-12。

- `version_comparison.pptx`：24 页，白底黑字 Times New Roman。
  - 第 1 页：版本表。每一行在上一行基础上加一样东西，列出加了什么、业务上能不能实时拿到、6 小时 RMSE（全部站 / 城市溪流 / 潮位站）。
  - 第 2 页：各版本按站点类型的 6 小时 RMSE 条形图。
  - 第 3 页：五个主要版本的 RMSE 随提前量变化（潮位站 / 河流 / 城市溪流）。
  - 第 4 页：试过但没有可测差别的改动（回看长度、层数、降雨取法、HRRR 的喂法等）。
  - 第 5 页：怎么看站点页。
  - 第 6–23 页：18 个站，一站一页，五个版本并排、两个事件窗口（飓风、飓风以外的最高水位）。
  - 第 24 页：三条路（保持现状 / 加 HRRR 降雨 / 找更好的降雨预报）和各自的数字。
- `versions_bars.png`、`versions_lead.png`、`station_<站号>.png`：幻灯片里的图。
- `versions_table.csv`：版本表的数字。`stations_summary.csv`：18 个站各版本全年 6 小时 RMSE。
- `data/`：`station_screen.csv`（所有业务站的完整度筛查）、`<站号>_obs.csv` 和 `<站号>_fc.csv`（窗口内的观测和各版本每 6 小时起报的 1–6 小时预报）。

## 版本

| 版本 | 加了什么 | 实时可得 | 6 h RMSE 全部站 (cm) |
|---|---|---|---|
| 只用水位 | 过去 72 小时水位 | 是 | 10.2 |
| + 过去风 | 站点处风，过去 72 小时 | 是 | 9.9 |
| + 未来风 | 未来 6 小时的风 | 是 | 9.8 |
| + 上游流量 | 最近的上游 USGS 流量站 | 是 | 9.7 |
| 流量改配同河、15 个内陆大河站关风（业务模型） | | 是 | 9.7 |
| + 过去降雨 | 15 km 实测雨，过去 72 小时 | 是 | 9.5 |
| + HRRR 预报降雨 | 未来 6 小时 HRRR 预报雨总量，用预报雨训练 | 是 | 9.0 |
| + 未来实测降雨 | 未来 6 小时实测雨 | **否**，上限 | 7.2 |

这里的数字只算业务站，所以和 13–16 号报告里含 CRMS 的数字（7.64、5.94 等）不同；CRMS 湿地站误差小、数量多，会把整体数字拉低。

## 站点怎么挑的

每类挑几个站：潮位站 3、河口 / 潮汐通道 3、湖 3、河流 5、城市溪流 4。条件：两个窗口里观测和五个版本的全部输入一个小时都不缺；测试期观测完整度 99.5% 以上。USGS 湿地站 9 个都有缺测，所以这一类没有放。有 3 个站原本的最高水位窗口（2024 年 6 月 17–21 日）缺风场数据，自动换成了下一个数据齐全的最高水位窗口。
