# deliverables

只放给人检查的文件，不放代码和中间数据。

| 文件 | 内容 |
|---|---|
| `00_overview.md` | 工作总览：从普查站点到 v4，每一步做了什么、结果多少、文件在哪，以及还没做的事 |
| `01_excluded_stations.md` / `.csv` | 普查到的全部站点中没有进入训练集的站，以及每个站被筛掉的原因 |
| `02_results.md` + `02_*.png` / `.csv` | 当前模型（v2，只用水位观测）在测试集 2024–2026、提前 1–6 小时的 RMSE：模型规模摸底、三个 domain 的整体情况、代表性站点的图 |
| `04_error_split.md` + `04_*` | 误差按时段（平静 / 高水位 / 风暴）和站点类型拆分，说明风场和流量各能补哪部分 |
| `05_inputs_summary.md` + `05_*` | 风场（AORC）和流量（USGS 上游控制站）两类新输入的来源、覆盖、统计、地图 |
| `06_wind_discharge_results.md` + `06_*` | 加风场和流量之后的四组对比（只用水位 / +过去风 / +过去风+未来风 / +风+流量）：按 domain、站点类型、风暴期拆分，变好和变差的站，流量为什么没起作用 |
| `07_human_control.md` + `07_controlled_stations.csv` | 误差大的站里哪些是人工调度（大坝放水、船闸、泵站）造成的，谁在管，调度数据有没有公开接口，下一步怎么接 |
| `08_same_river_discharge.md` + `08_*` | 流量改配同一条河上游站之后的结果（v4 对 v3）：改配的 49 个站、按河流、哪些站变好、大坝下游为什么没变 |
| `events/` | 事件尺度的预报图：36 个站各三个 4 天窗口，每 6 小时起报的 1–6 小时预报轨迹叠在观测上（索引 `events/README.md`） |
| `09_logic.md` | 到目前为止的逻辑：误差预算、证据链、三类站各自能用什么补、哪些事做了也没用、要组里定的两件事 |
| `10_representative/` | 代表性站点：每个 domain 每类几个站，飓风 / 涨水 / 平常三个窗口的预报图、误差范围对比、位置图、汇总表和幻灯片 |
| `11_figures/` | 论文风格重画：23 个代表站的三联图（提前 1 / 3 / 6 小时连续线）、RMSE 随提前量曲线、按类型箱线图、RMSE 地图、28 页幻灯片 |
| `03_plan_wind_discharge.md` | 只用观测做到什么程度之后再加风场和流量数据的计划 |
