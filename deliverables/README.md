# deliverables

只放给人检查的文件，不放代码和中间数据。

| 文件 | 内容 |
|---|---|
| `00_overview.md` | 工作总览：从普查站点到 v4，每一步做了什么、结果多少、文件在哪，以及还没做的事 |
| `01_excluded_stations.md` / `.csv` | 普查到的全部站点中没有进入训练集的站，以及每个站被筛掉的原因 |
| `02_results.md` + `02_*.png` / `.csv` | 当前模型（v2，只用水位观测）在测试集 2024–2026、提前 1–6 小时的 RMSE：模型规模摸底、三个 domain 的整体情况、代表性站点的图 |
| `04_error_split.md` + `04_*` | 误差按时段（平静 / 高水位 / 风暴）和站点类型拆分，说明风场和流量各能补哪部分 |
| `05_inputs_summary.md` + `05_*` | 风场（AORC）和流量（USGS 上游控制站）两类新输入的来源、覆盖、统计、地图 |
| `06_wind_discharge_results.md` + `06_*` | 加风场和流量之后的四组对比（只用水位 / +过去风 / +过去风+未来风 / +风+流量）：按 domain、站点类型、风暴期拆分，变好和变差的站，流量为什么没起作用 |
| `07_human_control.md` + `07_controlled_stations.csv` | 误差大的站里哪些是人工调度（大坝放水、船闸、泵站）造成的，谁在管，调度数据有没有公开接口，下一步怎么接 |
| `08_same_river_discharge.md` + `08_*` | 流量改配同一条河上游站之后的结果（v4 对 v3）：改配的 49 个站、按河流、哪些站变好、大坝下游为什么没变 |
| `events/` | 事件尺度的预报图：36 个站各三个 4 天窗口，每 6 小时起报的 1–6 小时预报轨迹叠在观测上（索引 `events/README.md`） |
| `09_logic.md` + `09_groups_*` | 到目前为止的逻辑：误差预算、证据链、三类站各自能用什么补、要组里定的两件事；第九节是分组训练实验的结果（不分组），第十节是 15 个大河站风置零的结果（业务模型改用 v6_wind_q） |
| `10_representative/` | 代表性站点：每个 domain 每类几个站，飓风 / 涨水 / 平常三个窗口的预报图、误差范围对比、位置图、汇总表（幻灯片已并入 11）|
| `11_figures/` | 论文风格重画：23 个代表站的三联图（提前 1 / 3 / 6 小时连续线）、RMSE 随提前量曲线、按类型箱线图、RMSE 地图、28 页幻灯片 |
| `12_crms_realtime.md` | CRMS 站能不能进业务系统：CPRA 只有 10 个 CRMS 水文站是实时的，且目前没有公开近实时渠道；建议业务清单去掉 CRMS |
| `13_rain.md` + `13_rain_*` | 降雨实验：加 AORC 降雨（点值 / 15 km 均值，过去 72 h / 加未来 6 h）后的逐站对比。未来 6 h 降雨让城市溪流中位数 12.9 → 7.9 cm、整体 7.64 → 5.94 cm；只加过去降雨几乎没用；结果依赖降雨预报质量，业务模型暂不变 |
| `14_arch.md` + `14_arch_*` | 结构实验：回看 168 / 336 h、3 层 LSTM 对比当前模型，整体都在 ±0.05 cm 以内，结构不变 |
| `15_hrrr_rain.md` + `15_hrrr_*` | 用 HRRR 预报降雨代替实测降雨重算降雨模型：完美预报整体 5.95 cm，HRRR 起报周期 7.39，前 1 小时周期 7.66（当前模型 7.65；11-10 更正了起报对齐）；HRRR 逐小时降雨在站点上相关只有 0.3–0.5，收益几乎全被预报误差吃掉；要拿到部分收益必须用预报降雨训练 |
| `16_rain_forecast_trained.md` + `16_rain_fc_*` | 用 HRRR 预报降雨训练未来 6 小时那一段（5 组：逐小时 / 总量，15 / 45 km，两种周期）：整体 6 h RMSE 7.65 → 7.2 cm（−5%），城市溪流中位数 −0.9 cm；五组无差别；约为实测雨上限（5.95）的四分之一；业务模型暂不变 |
| `17_versions/` | 各版本横向对比：从只用水位到加风、流量、降雨（实测 / HRRR 预报）的 8 个版本，按站点类型的 RMSE，各版本的站点 RMSE 地图和变化量地图，18 个记录完整的站五个版本并排的事件图，26 页幻灯片，最后一页列出三条路 |
| `03_plan_wind_discharge.md` | 只用观测做到什么程度之后再加风场和流量数据的计划 |
